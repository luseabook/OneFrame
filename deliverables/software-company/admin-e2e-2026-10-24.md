# 运营后台验证记录（2026-10-24）

> 目标：让 MVP 具备可运营性（独立管理员鉴权 + 审计/下架）。

## 实现

| 能力 | 端点 |
|---|---|
| 管理员登录 | `POST /ops/admin/login`（scrypt 密码校验，JWT issuer=oneframe-admin，独立于用户 token） |
| 概览 | `GET /ops/admin/dashboard`（用户/任务分布/导出/有效分享/管理员数） |
| 模型上下架 | `GET /ops/admin/models`、`PATCH /ops/admin/models/:id`（visible/sort） |
| 价格 | `GET /ops/admin/model-prices`、`PATCH /ops/admin/model-prices/:id` |
| 任务审计 | `GET /ops/admin/tasks`（分页/状态） |
| 导出审计 | `GET /ops/admin/exports` |
| 分享管理 | `GET /ops/admin/shares`、`POST /ops/admin/shares/:id/revoke`（运营下线） |
| Web | `/admin`：登录、概览、模型/价格、任务审计、分享管理 |

安全：
- 管理端路由对全局用户 AuthGuard 标记 `@Public()`，但由 `AdminGuard` 强制校验管理员 JWT；无 token 返回 401101；
- 非生产环境首次启动自动创建 `admin/admin12345`；生产必须显式设置 `ADMIN_USERNAME/ADMIN_PASSWORD`；
- 密码 scrypt 加盐哈希存储于 `admin_users`。

## 验证

- API 测试 `admin.spec.ts` 5 项：登录、dashboard、模型上下架、三类审计列表、无 token 拒绝；
- 全仓 API 测试 **26 项**通过；
- 浏览器：`/admin` 登录后概览显示 用户3/任务2/导出1/分享0/管理员1（截图 `admin-ui-e2e-2026-10-24.png`）。
