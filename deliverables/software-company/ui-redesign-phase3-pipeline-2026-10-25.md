# UI 重构 · 第二阶段：流水线工作台

> 2026-10-25 · 在 phase1 设计系统之上重做项目流水线页。

## 一、重构内容（`pages/projects/[id].vue`，1045 → 1587 行）

原实现是「4 个 button 页签 + 文本域堆叠」，无信息层级。现改为竞品同构的三段式工作台：

### 1. 页头（Page Head）
- 返回链接 + 项目标题（2xl 字号）+ 元信息（画幅 · 集数 · 角色数）；
- 右侧来源标签（小说改编 / 一句话想法 / 导入剧本）。

### 2. 步骤条（Pipeline Stepper）
- 4 步等宽分布：大纲 → 角色 → 分镜 → 投递；
- 每步显示序号圆点、标题、该步数据量徽标；
- **完成态**（该步数据已就绪）显示 ✓ 且圆点转绿色，当前步高亮紫底。

### 3. 工作区（Workspace）
- **左侧分集栏**（232px，sticky）：集号 + 标题 + 状态标记，选中态紫底；空态引导；
- **右侧舞台区**（自适应，min 420px 高）：按步骤切换内容。

### 各步骤的界面
| 步骤 | 界面 |
|---|---|
| ① 大纲 | 卡片网格（auto-fill 260px），卡内可编辑标题（下划线式输入）+ 梗概，focus-within 高亮；空态带「生成大纲」CTA |
| ② 角色 | 角色卡网格，4:3 定妆图区 + 状态角标（已定稿/待定稿）+ 描述 2 行截断 + 「生成定妆图 / 定稿 / 候选图 / 转通用资产」操作组 |
| ③ 分镜 | 6 列表格（镜号/画面/提示词/时长/角色/操作），单元格为无边框 textarea，悬停显边框、聚焦高亮；剧本草稿折叠面板；空态 |
| ④ 投递 | 调度条（模型选择 + 预算 + 按报价预填 + 导出 zip + 重试）；预算触顶警告条；分镜素材缩略图；**分镜矩阵**（按集分行，格子按状态着色 + 图例）；批次结果列表（已提交/资产未定稿/超预算 + 任务状态） |

## 二、设计要求落地

| 要求 | 实现 |
|---|---|
| 信息层级 | 页头 2xl → 区块 lg → 卡片 base → 辅助 xs，4 级字号分明 |
| 状态可视化 | 步骤圆点（完成/当前/待办）、状态 Tag（6 tone）、矩阵色块 + 图例 |
| 反馈 | 悬浮提示条（error/info/warning/busy）+ busy 脉冲点 + Transition 淡入 |
| 一致性 | 全部复用 phase1 组件（Button/Tag/EmptyState/Modal）与设计令牌 |
| 响应式 | ≤1100px 分集栏转横滑；≤760px 分镜表收为 3 列（隐藏提示词/角色列） |
