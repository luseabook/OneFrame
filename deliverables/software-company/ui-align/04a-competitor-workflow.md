**最值得对齐的 5 个功能缺口**（对本项目而言，按"复刻收益 ÷ 成本"排序）：
1. **「@ 主体」提示词编辑器**：提示词用 tiptap 富文本，支持 `@` 引用素材 + 8 类词库（官方词库/团队自定义/运镜库/特效模版库/高级预设/色板库/参考提示词/白模参考）。我方是纯文本 textarea + 勾选式资产绑定，缺"提示词即素材编排"的心智。
2. **左列分镜条 = 镜头导航 + 状态机**：`AI拆分镜(首次免费)` → `分镜(N)` → 逐卡 `未定稿` 状态 + 选中即联动中/右列。我方镜头是表格/矩阵，缺"逐镜推进"的节奏感。
3. **项目资产是「左侧 sheet + scrim」，覆盖中列不覆盖生成台**：让"挑资产"时仍能看见右侧提示词与参数。若我方做成居中 modal 或右侧抽屉，会打断核心手部动作。
4. **生成台底部 sticky 参数条 + CTA 内嵌报价**：`1080P 优惠版 / 5秒 / 1个 / 立即生成 ✦ 63` 压成一行，成本透明且零跳转。
5. **统一三态与轻反馈语言**：`暂无素材 或 本地上传` / `加载中...` / `没有更多了...` / `加载标签分组失败`（浅底红叉胶囊）+ 解释性内容走紫色气泡卡片。这套"短句 + 就地插画"的空态语言，是"看起来像同一个产品"的一半。
