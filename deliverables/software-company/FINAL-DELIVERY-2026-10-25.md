## 二、产品形态落地

### 2.1 形态定义（A 型纯 SaaS 自助）
只交付软件，用户自助注册→自助出片→自助下载/分享；不做代运营、不做人工交付。
人工介入仅限：内容审核申诉、账号注销恢复、举报处置。

**推论**：留存取决于「第一次能否自己出成片」与「是否会回来做第二集」→ 作品库与二次创作是 P0。

### 2.2 留存闭环（全链路可验证）

```
新用户 → 引导条(3步) → 示例模板作品 → 复制为我的项目 → 生成分镜 → 批量投递 → 出片
                            ↓                                                    ↓
                        作品库可见成果 ←───────────────────── 续做下一集 / 角色复用
```

| 环节 | 实现 | 验收 |
|---|---|---|
| 有可看的东西 | 注册即赠示例作品（2 集+2 角色，无分镜） | ✅ |
| 知道怎么做 | 引导条 3 步 + 项目页状态提示 | ✅ |
| 能自己动手 | 复制示例 → 分镜 → 投递 → 出片 9/10 镜 | ✅ |
| 看到成果 | 作品库聚合（集数/出片数/进度条/封面/四态） | ✅ |
| 再来一次 | 续做一集、角色复用、副本隔离（深拷贝验证） | ✅ |

## 四、本轮迭代修复的真实缺陷汇总

| # | 缺陷 | 严重度 | 修复 |
|---|---|---|---|
| 1 | `duplicate` 返回 BigInt 导致 500 | 高 | `String(id)` |
| 2 | 余额不足导致投递整单失败，新用户什么都拿不到 | **高** | 改为逐镜截断（9/10 镜成功） |
| 3 | 投递失败不给原因 | 中 | 按错误码给可行动文案 + 跳转入口 |
| 4 | 投递后矩阵不刷新 | 中 | 投递后 reload |
| 5 | 作品库封面用对象键当 URL（404） | 中 | storage 签名，图片资产→定妆图回退 |
| 6 | `definePageMeta({ssr:false})` 不足以防 hydration mismatch | 中 | 路由级 routeRules 关闭 SSR |
| 7 | 布局顶栏 ClientOnly 导致节点数差异 | 中 | 移除，改 auth-ready 门控 |
| 8 | 示例作品有接口无入口，闭环断开 | **高** | 补「复制为我的项目」 |
| 9 | 静态资源 404 致 Vue 未挂载 | 高 | 清理重建 + 重启进程 |
| 10 | nginx upstream 缓存旧容器 IP 全站 502 | 高 | resolver + 变量运行时解析 |
