# AI 双标识验证记录（2026-10-24）

> 目标：《AI 生成合成内容标识办法》+ GB 45438 的显式 + 隐式标识最小闭环。

## 实现

- worker 任务成功后 `labelResults`（`apps/worker/src/label.ts`）：
  1. **隐式**：写入旁车 `u/.../r0.mp4.ai.json`（ai_generated/text/task_id/generated_at），并回写 task result `meta.ai_label`；
  2. **显式**：ffmpeg `drawtext` 叠加「AI生成」水印，写入 MP4 metadata `comment=AI-generated content (OneFrame AI)` / `artist=OneFrame AI` / `ai_generated=true`；
  3. 失败降级：无 ffmpeg/媒体不可解码 → `explicit=false` + `explicit_reason`，仍保留隐式标识；
- 导出 zip 的 `manifest.json` 增加 `ai_label` 汇总与逐镜标识；
- 公开分享结果带 `ai_label`（隐式字段）。

## 实测（本地 ffmpeg 8.1.1）

生成 1s 测试 mp4（2326B）→ labelResults(explicit)：

```
{"enabled":true,"ai_generated":true,"text":"AI生成","generator":"OneFrame AI",
 "task_id":"2","explicit":true,"implicit":true,"sidecar_uri":"u/1/tasks/2/r0.mp4.ai.json"}
bytes 2326 -> 2840（水印重编码）
ffprobe format.tags:
  artist = OneFrame AI
  comment = AI-generated content (OneFrame AI)
```

隐式旁车可读；unit test 覆盖 ffmpeg 不可用时降级（`explicit=false`、仍写 sidecar）。
