# S3 存储驱动 + 任务分享验证记录（2026-10-24）

> 目标：补齐生产存储路径（local → S3/OSS）与 F3 结果分享。

## S3/OSS 驱动

- `@app/storage` 新增 `S3Storage`：`@aws-sdk/client-s3` + presigner；
- 支持 AWS S3 / 阿里云 OSS S3 兼容端点 / MinIO；`forcePathStyle` 可配；
- 下载统一 `GET` 预签名 URL（不开放桶公网）；上传/读取走 SDK。

测试（无需网络，预签名本地计算）：

```
S3Storage.signDownload("u/1/tasks/2/r0.mp4", 3600)
→ http://127.0.0.1:9000/app-results/u/1/tasks/2/r0.mp4
   ?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Expires=3600&X-Amz-Signature=<64hex>
```

env（api/worker 同）：`STORAGE_DRIVER=s3`、`STORAGE_S3_BUCKET/REGION/ENDPOINT/ACCESS_KEY_ID/SECRET_ACCESS_KEY/FORCE_PATH_STYLE`。

## 任务分享（F3）

| 端点 | 说明 |
|---|---|
| `POST /tasks/:id/share` | 生成 ≥128bit token，默认 7 天，返回 `share_path` |
| `DELETE /tasks/:id/share` | 撤销（revoked_at） |
| `GET /share/:token` | 公开只读：任务模式/状态/结果预签名 URL/过期时间，不含 space/user/积分 |

- 数据表 `task_shares`（迁移 0003）：token unique、expires_at、revoked_at；
- API 测试：创建分享 → 匿名 GET 成功 → 撤销 → 再 GET 返回 400102；
- Web：任务详情「生成分享链接/取消分享」，`/share/:token` 公开页展示结果与下载；
- 分享结果 URL 为 1h 预签名，链接本身 7 天有效。
