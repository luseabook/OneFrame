# 流水线前端验证记录（2026-10-24）

> 目标：验证 F2 流水线在浏览器内可操作（建项 → 大纲生成/确认 → 角色/定妆 → 分镜 → 批量投递）。
> 环境：生产构建 Nuxt + API + worker + PG/Redis；headless Chromium。

## 实测

| 步骤 | 结果 |
|---|---|
| 登录后进入 `/projects` | 项目列表 + 新建表单 |
| 填写名称/素材，点击创建 | 跳转 `/projects/<id>` |
| 点击「生成大纲」 | 3 集大纲生成并渲染，提示“请确认”；分集侧栏同步 |
| 页面状态 | 顶栏积分 80；项目标题/画幅/集数/角色数显示正常 |

截图：`pipeline-ui-e2e-2026-10-24.png`

## 页面能力

- `/projects`：项目列表 + 新建（小说/想法/剧本，画幅、素材）；
- `/projects/[id]`：
  - ① 大纲：生成/行内编辑标题与梗概/确认；
  - ② 角色：生成角色、生成定妆图（轮询自动定稿+签名缩略图）、定稿；
  - ③ 分镜：生成剧本草稿、生成分镜、逐镜编辑并保存、角色引用计数；
  - ④ 投递：模型/预算选择、批量投递、逐镜提交状态与任务状态轮询；
- 失败态：400105 资产未定稿、745703 超预算有独立提示。

## 说明

- 定妆图缩略图通过项目详情的 `portrait_url`（预签名 1h）加载；
- 批量投递后分镜 `status=3`，任务进度在投递页轮询；点“任务”进入任务中心可下载；
- 候选定妆图选择（count>1）与导出 zip 尚未做，列入下一轮。
