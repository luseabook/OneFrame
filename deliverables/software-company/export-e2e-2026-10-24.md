# 导出 zip + 分镜状态回写验证记录（2026-10-24）

> 目标：验证整集导出异步化（PENDING→PACKAGING→SUCCEEDED）与分镜状态回写。
> 环境：PG18(55432) + Redis(6380) + api(3000) + worker(mock/local storage)。

## 实测

| 步骤 | 结果 |
|---|---|
| 建项→大纲→角色→定妆→4 分镜→批量投递 | 4 任务全部成功 |
| worker 成功后分镜回写 | 4 镜 `status=5`（出片） |
| `POST /projects/:id/episodes/:eid/exports` | 返回 `export_id`，status=1 |
| 轮询 `GET .../exports/:xid` | status=3（SUCCEEDED），返回 1h 预签名 `download_url` |
| 下载 zip | `shot-01..04.mp4`（各 43B mock）+ `manifest.json`（1316B，4 镜） |
| 过期 | `expires_at = now + 7d` |

## 实现要点

- `exports` 表（迁移 0002）：`status/file_uri/expires_at/error`；服务端仅暴露预签名 URL；
- 队列 `export.zip`：worker 读取已成功镜头的存储对象，打包 mp4 + manifest（镜号/时长/提示词/任务号）；
- 无可用视频时 status=4（错误码 400106），前端提示补齐；
- 分镜回写：视频任务成功 → `status=5`；失败/审核拒绝 → `status=2`（可重新投递）；出图任务成功 → `status=4`；
- 导出文件存 local driver，生产替换 OSS/S3 后 URL 语义不变。
