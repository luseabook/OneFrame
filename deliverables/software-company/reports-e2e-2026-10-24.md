# 举报通道 + 运营处置验证记录（2026-10-24）

> 目标：补齐合规 C2（举报投诉通道 + 违规内容即时下线）。

## 实现

| 层 | 内容 |
|---|---|
| 数据 | `content_reports`（迁移 0004）：task_id/share_id/reason/detail/contact/status/handled_by/handled_at/resolution |
| 公开入口 | `POST /share/:token/report`（@Public，token+IP 每小时 5 次频控） |
| 运营端 | `GET /ops/admin/reports`、`POST /ops/admin/reports/:id/resolve {action: takedown|dismiss}` |
| 处置效果 | takedown 自动撤销对应 `task_shares.revoked_at`，公开页立即 400102 |
| Web | `/share/:token` 举报表单；`/admin` 「举报处置」页签（下线/驳回） |
| 审计 | 记录处理人 adminId、处理时间、resolution 备注 |

## 验证

API 测试（flow.spec）：

```
创建分享 → 匿名 POST report(reason=illegal) → code0
管理员登录 → GET /ops/admin/reports 找到该报告(status=1)
POST resolve {action:takedown} → status=2
匿名 GET /share/:token → 400102
```

浏览器：`/admin` 举报处置页显示“已下线 / illegal / test report / 违规下线”。

截图：`reports-ui-e2e-2026-10-24.png`

## 说明

- 频控依赖 Redis；生产可叠加 WAF/验证码。
- 当前只撤销被举报分享 token；如需下架同一任务全部分享/任务，可扩展为任务级处置。
- 管理员操作尚未写独立审计表（当前在 content_reports.handled_by/handled_at 留痕）。
