## 1. 愿景

**让一个人在 30 分钟内产出一集可发布的漫剧/短剧视频。**

> 口径说明（双口径）：30 分钟指**人工操作时长**（用户编辑/确认动作的累计活跃工时）；端到端验收口径（含生成排队等待）≤2h，见 §4 F2 验收标准。"可发布成片"的自动合成（拼接+BGM）为 v1.1 承诺，首发导出形态为逐镜下载/全集 zip。

MVP 必须直接兑现愿景：流水线（小说/想法 → 大纲 → 角色 → 分镜 → 批量成片）是旗舰，工具箱只是入口。单点工具是模型厂商的正面战场（即梦/可灵官方前端+免费额度），聚合器按积分加价无胜算；我们的生存空间在"生产流水线 + 角色一致性 + 批量"，竞品 700+ 端点中 df/* 剧本工厂占半壁江山印证了这一点〔RM-证据：路由表统计〕。

## 2. 目标用户与画像

| 画像 | 描述 | 核心诉求 | 与 MVP 关系 |
|---|---|---|---|
| **P1 个人创作者**「阿凯」 | 25 岁抖音/快手短剧创作者，单人产出，周更 2~3 集 | 低门槛起步、单集成本低、出片快 | 旗舰用户：一句话→一集 |
| **P2 小工作室**「林姐」 | 3~5 人短剧工作室，月产 10~30 集 | 批量生成、角色一致性、资产管理 | 分镜批量+预算上限为其设计 |
| **P3 MCN/批量方**「陈总」 | 50+ 集月产，矩阵号运营 | API/批量、成本可控、私有化 | v1.1+（API 开放）再服务 |

## 3. 价值主张与差异化

1. **流水线首发即差异化**：不是"又一个文生视频站"，而是"小说粘贴进去、成片拿出来"；
2. **角色一致性机制化**：定妆图绑定 → 全分镜自动注入参考（竞品 df 域核心壁垒的极简实现）；
3. **价格透明**：官网公示直连价与积分换算（对照竞品积分黑盒〔RM-证据：定价页〕）；
4. **BYOK**（v1.1 后）：用户自带模型 Key，平台收软件费；
5. **模板市场**（v1.5+）：一句话工作流 UGC+分成。

## 4. MVP 范围（v1.0 首发）

### F1 账号与登录 — P0

**规格**
- 登录方式：手机验证码（6 位数字，有效期 5 分钟；同一验证码错误校验 5 次后作废，一次一用）；
- 发码频控：单手机号 1 条/60s、5 条/日；单 IP 20 条/时；触发频控/风控返回 429101 行为验证码挑战（前端弹验证码，票据随重试提交）；
- **Alpha 期注册需邀请码**：登录表单含邀请码字段；无有效邀请码不能建号，只能进入等待名单（留手机号，J3a）；
- 未注册自动建号：持有效邀请码首次验证码登录即创建用户/个人空间/积分账户，并赠送 **80 积分**（仅首登一次）；同号重复登录不重复赠送；
- 注销入口：设置页提供账号注销（注销后 30 天物理清理，任务记录脱敏，口径见 security.md）；
- 年龄门禁（最小实现）：注册协议含"已满 18 周岁"**强制勾选**，未勾选不可注册（勾选时间留痕，承接 F7/compliance C3）。

**验收标准**
- 新号（持有效邀请码）从打开登录到进入工作台 ≤3 步（手机号→验证码→进入），登录后余额即显示 +80；
- 同一手机号重复登录不重复赠送（积分流水仅一条 gift +80）；
- 发码频控生效：同号 60s 内第二次请求被拒并显示倒计时；同号当日第 6 条被拒；
- 无邀请码用户提交后进入等待名单提示页，不产生账号与积分流水。

### F2 剧本流水线（旗舰） — P0

从新建项目到逐集出片的完整链路，**表格/向导式 UI（非画布）**：

| 环节 | 功能 | 规格 |
|---|---|---|
| ① 建项 | 新建项目 | 标题、类型(真人/动漫)、画幅(默认 9:16，模型目录 `ratios` 内)、来源：**粘贴小说 ≤5 万字 / 一句话想法 / 导入已有剧本 ≤5 万字（按集拆分）**〔RE：制片工坊「导入剧本→拆集」主路径〕 |
| ② 大纲 | AI 分集大纲 | DeepSeek 生成 **P95≤20s、硬超时 30s**（与 api-spec §8 一致，超时报 745901 可重试不扣费）；分集列表(集号/标题/梗概)可增删改；generate 即落草稿、编辑**自动保存**（刷新不丢稿）；PUT 为确认提交 |
| ③ 角色 | 角色卡 | 从大纲/剧本自动抽取(≤10 张，含场景/道具清单可后续补)；可编辑名称/描述/提示词；**定妆图**=生成任务(1~4 候选选一绑定，资产生图用 `mode=studio_asset_image`)，支持以已选定妆图改稿(image2image)；**定稿**=绑定后 `project_assets.status=2`（未定稿角色不得被分镜引用，投递时报 400105）〔RE：资产必须定稿且有 file_id 才能被分镜匹配〕 |
| ④ 剧本 | 集剧本草稿 | 按集生成(可编辑)；与分镜生成解耦；**可跳过、默认折叠**（直接大纲→分镜，缩短首次体验） |
| ⑤ 分镜 | 分镜表 | 按集生成(**默认 10 镜，可调 4~30**，产品口径、与模型无关)；字段：镜号/画面描述/视频提示词/时长(秒，默认 5，输入 1~30)/绑定角色(多选)；行内编辑/增删/重排。**时长/画幅/分辨率不写死档位**：选项由 `/models` 的 `storyboard_reference_video` 渲染，投递时就近取模型合法低档并回写 `duration_s`（RE 实证各模型不同：天幕2.0 仅 5s、可灵2.6 5/10、TS2.0 4/8/12、TV3.1 4/6/8） |
| ⑥ 批量 | 批量生视频 | 选集或选镜 → **必填预算上限(默认=`POST /credits/quote/batch` 的 total_credits)**；逐镜建任务(mode=universal_reference + scene=storyboard_reference_video，references=已定稿角色图，服务端强制注入)；**投递前校验**：未定稿角色→该镜 400105、参考图数超模型 media_limits→400101；断点续跑：失败镜一键重试(幂等不重复扣费)；**预算触顶→该镜 `submitted:false, code:745703, reason:budget_exceeded`，接口 200 部分成功**；续投需**显式输入新预算上限**(预填"已消耗+剩余镜头报价")；**余额不足(745701)**→整单拒 + 充值引导(Beta)/等待名单(Alpha) |
| ⑦ 导出 | 逐镜下载/全集打包 zip | **异步导出任务**：提交→完成通知(轮询/SSE)→下载；**只打包 SUCCEEDED 镜头 + `manifest.json`(缺失/失败镜标注)**，成功镜 <80% 时拒绝(400106)；成片合成拼接(含 BGM)→ v1.1〔RE：export merge 只合并已定稿视频，不生成缺失镜〕 |

**验收标准**
- 粘贴 1 万字小说（≤5 万字）或导入 1 万字剧本 → 3 集×10 镜全部完成：**人工干预 ≤5 次**，端到端（含排队）≤2h（人工操作时长目标 30min，双口径见 §1）；
- 一致性机制：同角色各镜任务 references 均含其**已定稿**定妆图（服务端保证）；未定稿的镜返回 400105 并标"待定稿"，补定稿后可续投；角色换绑仅影响后续新任务；
- 预算上限：投递前用批量报价总额预填；预算触顶时该镜返回 `submitted:false + code:745703`（HTTP 200 部分成功），余镜标"未投递"；续投必须显式输入新预算值（预填"已消耗+剩余镜头报价"）；余额不足整单 745701 且不落任务；
- 时长/画幅/分辨率：UI 只展示所选模型 scene 枚举；提交值越界被 400101 拒绝；模型不支持当前时长时按就近低档回写（记录 `duration_adjusted`）；
- LLM 步骤（大纲/角色/分镜/剧本）生成失败、超时(745901)或审核未过 → 明确报错（定位到环节）可改写重试，不产生半写状态，不扣积分；同步端点硬超时 30s；
- 失败镜一键重试幂等，不重复扣费（原任务解冻后新任务按报价扣费，净额=一次）；
- 导出任务提交后可查询状态，完成后 zip 可下载（仅含成功镜 + manifest，<80% 时 400106），失败可重试；
- LLM 步骤单次消耗 1~2 积分，失败不扣。

### F3 工具箱（入口定位） — P1

保留 2 个：**文生视频、图生视频**。定位：获客漏斗 + 高级单点用法。

**规格**
- 两个独立页面（文生视频/图生视频），**三栏布局**：左=参数面板（提示词/模型/画幅/分辨率/时长/张数/音效开关）、中=结果预览（播放/候选切换）、右=生成历史（卡片式，状态轮询）；
- 图生视频支持首帧上传（OSS 直传+进度+格式校验）；
- 提交前 quote 实时积分预估（含划线价与预估后余额，价格透明）；余额不足提交 → 745701 → 充值引导（Beta）/等待名单引导（Alpha，J3a）；
- 生成中卡片 5s 轮询（ETag 304），支持取消与失败重试；
- 成片结果**带 AI 标识**（显式水印+隐式元数据，同 F7）；
- 结果操作：下载（预签名 URL 24h）、分享（公开只读预览链接，**默认 7 天过期、可撤销**，不含提示词与账号信息）、**转存资产库**、**"加入项目当分镜素材"**（引导建项/选项目）。

**验收标准**
- 从落地页"免费生成"到提交一次文生视频任务 ≤3 步（登录→参数→提交），全程可见积分预估；
- 余额不足提交被拒（745701）并弹出对应引导，不发任务不冻结积分；
- 首帧上传失败（超限/格式错误）有明确提示，不阻塞重试；
- 任一成片结果页与下载文件均含 AI 标识；
- "下载/分享/转存资产/加入项目"四操作均可用；分享链接可撤销、7 天后失效，撤销后公开预览返回 404。

### F4 任务与历史 — P0

**规格**
- 任务列表：按状态/能力(capability)筛选，分页，卡片含模型/模式/缩略图/积分/创建与完成时间；
- 任务详情：input/options 回显、结果预览、task_events 摘要；
- 操作：取消（PENDING/RUNNING→CANCELED+解冻；终态不可取消）、失败重试（复制原参数建新任务，幂等键服务端派生，不重复扣费）、单条下载（预签名 URL 24h）、**批量下载 zip（≤50 项）**、**分享（7 天可撤销）**；
- 轮询：批量 ids 查询 5s 间隔，响应带 ETag，3s 内重复轮询 304；
- **项目分镜矩阵视图**：按项目/集聚合"镜×状态"矩阵（绿=成功/黄=在途/红=失败/灰=未投递/**紫=待定稿**）+ 断点续跑入口（失败镜重试、未投递镜续投、待定稿镜先去定稿）。

**验收标准**
- 3 集×10 镜项目页可直接看出哪些镜待定稿/待投/在途/失败/完成，矩阵状态与任务实际状态一致；
- 取消运行中任务，冻结积分即时解冻并在余额可见；
- 失败镜一键重试产生新任务且不重复扣费；
- 批量下载 50 条任务打包 zip 成功；
- 高频轮询（30 次/分）下 304 命中，轮询接口 P95 <200ms。

### F5 资产库 + 角色资产 — P1

**规格**
- 我的资产库：目录（层级文件夹）、标签、预览（视频播放/图片）、**回收站**（删除后 7 天可恢复，逾期物理删除）；
- 任务结果**一键转存**资产（任务卡片/结果页直接入库）；
- 项目内资产页：角色定妆图/场景图集中管理；
- 定妆图**"转存为通用资产"**：跨项目复用，自动打 `#角色A` 类标签；
- **生成结果 90 天到期机制（用户可见）**：任务结果文件保留 90 天后自动删除；到期前 7 天站内提醒，提醒与结果页提供"转存资产库"引导（转存后按资产规则长期保留）；协议与页面文案同步告知。

**验收标准**
- 从任务结果到资产库一键转存成功，资产可按目录/标签检索与预览；
- 回收站恢复可用，7 天后物理删除不可恢复；
- 定妆图转存通用资产后，在另一项目可检索并作为参考使用（带 #角色 标签）；
- 结果到期前 7 天收到站内提醒，提醒内可一键转存。

### F6 积分（Alpha 免费 / Beta 支付） — P0(只读)/Beta(支付)

**规格**
- 余额/冻结/流水三处展示（/me 概览 + 流水页）；"冻结中"文案向用户解释两阶段扣费（创建冻结→成功结算/失败解冻）；
- Alpha 期：邀请制，免费额度=注册 80 积分 + 邀请码加赠；额度用尽→ 等待名单引导（J3a）；
- **积分 Alpha/Beta 期永不过期**（`credit_flows` 不产生 expire 流水；批次制/有效期在 Beta 前再议，若启用须同步对账不变式与 `credits balance` 字段）；
- Beta：微信 Native/H5 支付，SKU 四档 **¥50/500、¥100/1000、¥300/3000、¥600/6000** 积分；订单、发票信息、未消耗部分退款（SOP）。

**验收标准**
- 任意操作序列后 **`balance == Σ delta` 且 `frozen == Σ frozen_delta`** 恒成立（等价 `balance+frozen == Σ(delta+frozen_delta)`；口径见 database §4，security/testing 同文）；
- 用户可从流水页还原任一任务的冻结/结算/解冻轨迹（含"冻结中"状态展示）；
- 支付成功回调 ≤3s 入账，余额与流水即时一致；
- 退款仅退未消耗部分，退款后积分与订单状态一致。

### F7 内容安全与合规展示 — P0

**规格**
- 输入审核：提示词/文本（含小说原文）敏感词过滤+供应商审核，未过返回 745801；
- 输出审核：视频/图片结果过供应商审核；**LLM 输出（大纲/剧本/分镜提示词）同样过审**，未过返回 745802；
- 审核未通过：错误**定位到具体环节**（建项/大纲/角色/剧本/分镜/投递），内容可改写后重试，**审核拒绝不扣费**；
- **AI 双标识**：所有生成结果（视频/图片）**显式水印+隐式元数据**双重标识；实现=worker 转存后处理（ffmpeg 烧录+mp4/XMP 写入+probe 校验，图片重编码剥 EXIF，见 system-design §3.2 / WBS 1'.8）；前端展示"内容由 AI 生成"声明（承接 compliance B3）；后处理失败不得结算/对外；
- 举报入口：全站页脚"举报/投诉"入口（处置 SOP 见 compliance C2）；
- 年龄门禁：注册协议"已满 18 周岁"**强制勾选**（承接 F1），勾选时间留痕。

**验收标准**
- 敏感输入被拦截且错误提示指向具体字段/环节，改写后重试成功且无扣费流水；
- LLM 步骤输出含敏感内容被拦截，不落半写状态（同 F2 失败处理）；
- 抽验任意成片：显式水印可见，且文件元数据含 AI 生成标识字段；
- 页脚举报入口可达、提交留痕；
- 未勾选"已满 18"无法完成注册。

### F8 管理后台（最小） — P1

**规格**
- **admin 独立鉴权**（admin_users 与用户体系隔离，独立登录与权限）；
- 模型管理：上下架/排序/参数枚举**热更**；计价热更（model_prices），即时生效并反映到 quote 与前端模型目录；
- 任务看板：失败率/队列深度/adapter 延迟/任务状态分布，可按状态/模型筛选；
- 流水线漏斗看板：建项→大纲确认→角色就绪→分镜确认→批量投递→完集，各环节流失率/耗时/退出率（数据源=metrics §2 漏斗事件）。

**验收标准**
- admin 与普通用户账号完全隔离，普通用户访问任何 /ops/admin 端点返回 403；
- 调价后 1 分钟内 quote 返回新价格，无需发版/重启；
- 漏斗看板各环节数据与埋点事件口径一致，可定位单环节流失率；
- 任务看板可筛选并导出失败任务清单。

### F9 作品库与二次创作 — P0

> 形态前提：**纯 SaaS 自助（A 型）**。不做代运营/人工交付，因此留存完全取决于「第一次能否自己出成片」与「是否会回来做第二集」。作品组织与二次创作因此是 P0。
> 详细规格见 `PRD-supplement-works-and-onboarding.md`。

**规格**
- **作品模型**：作品 = 项目（1:1，不新增表）；作品四态：草稿（无分镜）/ 制作中（有分镜未出完）/ 已成片（全部镜头成功）/ 已归档（软标记 `script_projects.archived_at`）；
- **作品库 `/works`**：以「剧」为单位的成果视图，聚合集数、分镜数、已出片数、封面、四态；支持状态筛选、归档/恢复、分页；
- **与任务中心分工**：作品库=用户视角的成果视图；任务中心=排障视角的执行视图，两者不合并；
- **二次创作**：
  - 续做下一集（`POST /projects/{id}/episodes`，≤10 集/次），复用已定稿角色（定妆图绑定关系），**不复制分镜内容**；
  - 跨作品复用：资产库 `#角色X` 标签取角色加入当前作品（沿用资产模块能力）；
  - 幂等：续做与复制均带幂等语义，重复提交不重复建集；
- **归档/恢复**：`POST /projects/{id}/archive {archived:bool}`，软标记，不影响数据。

**验收标准**
- 作品库正确聚合四态：有分镜未出完=制作中，全部出片=已成片，无分镜=草稿，归档后不再出现在默认列表；
- 从已成片作品点「续做一集」，新集出现且角色已就绪（无需重新生成定妆图）；
- 新增 N 集（N≤10）后 `episodes` 精确增加 N 条、无重复（幂等）；
- 作品库与任务中心数据口径一致（同一任务的出片数在两个视图可对上）。

### F10 新手引导（首次体验闭环） — P0

> 对应 compliance/留存口径：A 型自助的激活率完全由「首次自助出片」决定。

**规格**
- **引导条**：首次进入工作台展示 3 步引导（新建作品 → 生成大纲 → 投递出片），可「不再提示」；
- **持久化**：关闭状态写 `users.onboarded_at`，`GET /me` 返回 `onboarded` 字段，`POST /me/onboarded` 幂等标记；
- **示例作品**：新用户注册时自动创建示例项目（`is_sample=1`，2 集已确认大纲 + 2 个角色，**无分镜**），在作品库标注「示例模板」；
- **复制为我的项目**：`POST /projects/{id}/duplicate` 深拷贝骨架与角色（不复制分镜与任务），用户可在副本上直接动手；
- **状态提示**：项目页按状态给出下一步（无分集→生成大纲；有大纲角色无分镜→生成分镜）；
- **激活埋点**：`onboarding_viewed` / `onboarding_dismissed` / `first_project_created` / `first_outline_generated` / `first_task_submitted` / `first_result_downloaded`，四项全达=激活用户。

**验收标准**
- 新用户注册后 30 秒内可在作品库看到示例作品，且带「示例模板」标识与「复制为我的项目」入口；
- 引导条关闭后刷新页面不再出现（服务端持久化，不是 localStorage）；
- 复制示例后生成分镜，**母版示例不被改动**（深拷贝验证）；
- 项目页在无分集/无分镜状态下给出可行动的下一步提示。
