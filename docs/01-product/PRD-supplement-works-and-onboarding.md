# PRD 补充：产品形态与留存闭环（v1.4 增补）

> 2026-10-25 · 形态确认：**纯 SaaS 自助（A 型）** · 产品逻辑对齐竞品 ReelMate · 验证期不做支付
> 本文补齐 v1.3 缺失的「作品组织 / 二次创作 / 新手引导」三块，并给出留存闭环的规格与验收。

---

## 0. 形态澄清（A 型：纯 SaaS 自助）

| 项 | 定义 |
|---|---|
| 交付物 | 只有软件。用户自助注册 → 自助出片 → 自助下载/分享 |
| 不做 | 不做代运营、不做人工交付、不承诺"帮你做片" |
| 由此产生的系统要求 | ①注册转化漏斗可观测 ②额度与成本可控 ③内容风控自动化 ④**首次使用必须能自己走通** |
| 人工介入点 | 仅限：内容审核申诉、账号注销恢复、举报处置（运营后台） |

**推论**：A 型 SaaS 的留存完全取决于「用户第一次是否靠自己出成片」与「是否会回来做第二集」。因此作品组织与二次创作是 P0，不是 P2。

## 1. 作品组织模型（对齐竞品 series-manage / reelflow）

### 1.1 层级
```
作品（Work）          ← 用户视角的"我的作品"，一个作品 = 一部剧
 └ 项目（Project）    ← 生产容器（已有 script_projects），承载 角色/大纲/分镜
    └ 分集（Episode） ← 已有 episodes
       └ 分镜（Storyboard）→ 视频结果（Task results）
```

- **作品与项目是 1:1**（MVP 不引入独立 Work 表，用项目本身表达作品，避免双写不一致）。
- 作品卡片的封面 = 该作品"已成功出片"的第一个镜头缩略图；无成片则用画幅占位。

### 1.2 作品状态（用户可理解的四态）

| 状态 | 判定 | 界面 |
|---|---|---|
| 草稿 | 有项目无分镜 | 显示进度「待生成分镜」 |
| 制作中 | 有分镜、有任务在途/未投 | 显示进度条「12/30 镜已出片」 |
| 已成片 | 至少 1 集全部镜头成功 | 显示「可导出」，主按钮=导出 |
| 已归档 | 用户手动归档 | 折叠区，可恢复 |

### 1.3 作品库页面（`/works`，新增）

**布局**：顶部筛选 + 网格卡片
- 筛选：全部 / 制作中 / 已成片 / 已归档；排序：最近更新 / 创建时间
- 卡片信息：封面（4:3）、作品名、集数、已出片镜头数、最后更新时间、状态标签
- 卡片操作：继续制作（进流水线）、导出成片、分享、归档、删除（软删）
- 空态：引导「新建第一部作品」

### 1.4 与「任务中心」的分工
- **作品库 = 以"剧"为单位的成果视图**（用户视角，看的是作品）
- **任务中心 = 以"次"为单位的执行视图**（排障视角，看的是任务状态）
- 两者不合并；任务详情可跳转所属作品。

## 2. 二次创作（续做下一集）

### 2.1 核心场景
P1 用户做完第 1 集，要接着做第 2 集；P2 工作室要批量做第 4~30 集。两者是同一动作的不同规模。

### 2.2 规格
| 能力 | 规格 |
|---|---|
| 续做下一集 | 作品详情页「新增一集」→ 复制上一集的**角色（定妆图绑定关系）与画幅/模型偏好**，不复制分镜内容 |
| 角色复用 | 已有已定稿角色自动注入新集分镜（复用 `characters` 与 `portrait_asset_id`） |
| 跨作品复用 | 从资产库 `#角色X` 标签选取角色 → 加入当前作品（已有接口能力：`POST /assets/from-task` + 角色转资产） |
| 批量续做 | 一次新增 N 集（N≤10），仅生成空壳集，分镜仍需逐集生成（避免一次扣费过大） |
| 幂等 | 续做请求带 `Idempotency-Key`，重复提交不重复建集 |

### 2.3 验收
- 从已成片作品点「新增一集」→ 30s 内出现新集且角色已就绪（无需重新生成定妆图）；
- 新集分镜投递时，参考图自动带上一集已定稿角色（服务端注入，前端不需传）；
- 批量新增 5 集，`episodes` 增加 5 条、无重复。

## 3. 新手引导（首次使用闭环）

### 3.1 目标
新用户注册后，**不看文档、不找人问**，在 15 分钟内自己产出一段视频。

### 3.2 三处引导
| 位置 | 形式 | 内容 |
|---|---|---|
| 首次进工作台 | 顶部引导条（可关闭，仅首次） | 「3 步做出第一集：①新建作品 ②生成大纲 ③投递出片」+ 直达按钮 |
| 空态引导 | 各列表空态内嵌 | 作品库空态→「新建第一部作品」；分镜空态→「生成分镜」；投递空态→「选择模型开始投递」 |
| 示例项目 | 一键体验 | 提供 1 个只读示例作品（已带 3 集大纲 + 3 角色 + 10 分镜，未投递），用户可「复制为我的项目」后直接投递体验 |

### 3.3 引导完成埋点（用于转化观测）
- `onboarding_viewed` / `onboarding_dismissed`
- `first_project_created` / `first_outline_generated` / `first_task_submitted` / `first_result_downloaded`
- 四项全达成 = 激活用户（用于 Alpha 期留存口径）

## 4. 留存闭环（验证期北极星）

```
新用户 → [引导] → 建作品 → 出片 → 作品库可见成果 → 续做下一集 → 回访
                     ↑                                    ↓
                     └──────────── 角色/资产复用 ←────────┘
```

| 指标 | 定义 | 验证期观察目标 |
|---|---|---|
| 激活率 | 注册后 24h 内完成"建项目+出片+下载" | 观察口径，不设硬指标 |
| 二次创作率 | 7 天内创建第 2 集/第 2 部的用户占比 | 观察口径 |
| 作品完成率 | 有分镜的作品中达成"全部镜头出片"的比例 | 观察口径 |

> 口径说明（延续 PRD 双口径原则）：Alpha 期只做观测与归因，不作为发布门禁。
