## 2. 路由拓扑（短剧工作流相关）

```
剧本创作入口  /series-manage                              ← 侧栏壳 + 大标题「好故事一定有市场！」
全部项目      /reelflow/list                              ← 卡片列表（项目 / 已导出 两个 tab）
项目内 ①      /reelflow/edit/:projectId                   ← 时间线导出（剪辑器，左「剧集资产」+ 底部时间线）
项目内 ②      /series-manage/episode/:projectId           ← 单集分镜工作台（本链路核心）
新建          /reelflow/edit/create                       ← 空项目编辑器（同一编辑器，create 形态）
新建单集      /series-manage/episode/create               ← 空单集工作台
剧集资产      /asset                                      ← 左侧竖排 剧本 / 资产 / 剧集 三视图
资产清单校验  /series-manage/asset-confirm                 ← 校验 → 批量生成资产 → 自动生成提示词
资产提取      /series-manage/asset-extract                ← 需项目上下文；空路由仅剩页头（见 11 图）
```

实际跳转链（实测）：
`/reelflow/list` →「创建项目」→ `/reelflow/edit/create` →「返回分镜创作」→ `/series-manage/episode/create`；
已有项目：`/reelflow/edit/:id` ↔（返回分镜创作）`/series-manage/episode/:id`。

## 4. 逐页规格

### 4.1 P1 项目列表 `/reelflow/list`（图 `01-project-list.png`）

- 无侧栏、无页面标题；顶部仅一行 tab：`项目 (N)`（激活：白字 + 2px 紫下划线）/ `已导出`，位于左上（x≈24）。
- 空态：居中文件夹插画 + `点击下方创建一个新项目`；底部居中悬浮胶囊按钮 `创建项目`（约 236×68，r 全圆，深色 + 1px 边）。
- 有数据（实测 1 个项目）：
  - 时间分组标题 `今天`（14px，`--text-3`）。
  - 卡片约 **330×250**：上部缩略图区（≈310×140，深色渐变 + 居中播放图标）；下部标题 `证据项目`（14/700）、副行 `最后编辑于 10/25/2026, 6:04:45 PM`（12px 灰）、右下 `⋮` 更多菜单。
  - 卡片描边 1px 极淡，圆角 16；hover 出现 `编辑` 覆盖按钮（🟡 早前截图曾见 `编辑`，本次静止态未见）。
  - 网格：单列靠左，卡片宽 330、间距 24。
- 交互：点卡片 → `/reelflow/edit/:id`；`⋮` → 重命名/删除等（未展开 ❌）；`创建项目` → `/reelflow/edit/create`。

状态机（从 UI 文字推断 🟡）：`未开始 → 剧本 → AI拆分镜 → 分镜(N)`；`AI拆分镜` 旁带 `首次免费` 角标。分镜状态标签 `未定稿`（定稿后应变为其它态）。

交互：
- `添加分镜` → 分镜数 +1（实测 1 → 2）。
- `项目资产` → 打开右侧抽屉式弹窗（见 4.4）。
- `匹配资产` → 依据提示词从项目资产自动匹配（实测仅显示提示 `根据提示词内容自动匹配项目资产`）。
- `3D导演台` → 全屏浮层（见 4.6）。
- 模式 tab 切换后，下方模型/素材/参数区随模式变化（未逐模式取证 ❌）。
