## 2. 路由拓扑（短剧工作流相关）

```
剧本创作入口  /series-manage                              ← 侧栏壳 + 大标题「好故事一定有市场！」
全部项目      /reelflow/list                              ← 卡片列表（项目 / 已导出 两个 tab）
项目内 ①      /reelflow/edit/:projectId                   ← 时间线导出（剪辑器，左「剧集资产」+ 底部时间线）
项目内 ②      /series-manage/episode/:projectId           ← 单集分镜工作台（本链路核心）
新建          /reelflow/edit/create                       ← 空项目编辑器（同一编辑器，create 形态）
新建单集      /series-manage/episode/create               ← 空单集工作台
剧集资产      /asset                                      ← 左侧竖排 剧本 / 资产 / 剧集 三视图
资产清单校验  /series-manage/asset-confirm                 ← 校验 → 批量生成资产 → 自动生成提示词
资产提取      /series-manage/asset-extract                ← 需项目上下文；空路由仅剩页头（见 11 图）
```

实际跳转链（实测）：
`/reelflow/list` →「创建项目」→ `/reelflow/edit/create` →「返回分镜创作」→ `/series-manage/episode/create`；
已有项目：`/reelflow/edit/:id` ↔（返回分镜创作）`/series-manage/episode/:id`。

## 4. 逐页规格

### 4.1 P1 项目列表 `/reelflow/list`（图 `01-project-list.png`）

- 无侧栏、无页面标题；顶部仅一行 tab：`项目 (N)`（激活：白字 + 2px 紫下划线）/ `已导出`，位于左上（x≈24）。
- 空态：居中文件夹插画 + `点击下方创建一个新项目`；底部居中悬浮胶囊按钮 `创建项目`（约 236×68，r 全圆，深色 + 1px 边）。
- 有数据（实测 1 个项目）：
  - 时间分组标题 `今天`（14px，`--text-3`）。
  - 卡片约 **330×250**：上部缩略图区（≈310×140，深色渐变 + 居中播放图标）；下部标题 `证据项目`（14/700）、副行 `最后编辑于 10/25/2026, 6:04:45 PM`（12px 灰）、右下 `⋮` 更多菜单。
  - 卡片描边 1px 极淡，圆角 16；hover 出现 `编辑` 覆盖按钮（🟡 早前截图曾见 `编辑`，本次静止态未见）。
  - 网格：单列靠左，卡片宽 330、间距 24。
- 交互：点卡片 → `/reelflow/edit/:id`；`⋮` → 重命名/删除等（未展开 ❌）；`创建项目` → `/reelflow/edit/create`。

### 4.3 P3 单集分镜工作台 `/series-manage/episode/:projectId`（图 `03`/`04`/`05`/`06`）★核心

整体三列布局（1424 宽）：

| 右列（生成台） | ≈620 | 顶部 `图片生成 / 视频生成` 两 tab（带图标，激活紫色下划线）+ 右侧 `≡` 折叠；下方 5 模式 tab：`参考生视频 / 首帧生视频 / 文生视频 / 首尾帧生视频 / AI改视频`；`模型` 行（`Seedance 2.5` ♥）+ 灰字提示「为保证 Seedance 生成效果，请确保角色/含人物的图片均已保存为Seedance主体并审核成功」；`选择素材` 行（`已上传素材数：图片 0/30，视频 0/10，音频 0/10，总素材数量 0/50`）+ 右上 `3D导演台`；两张上传大卡 `+ 项目资产` `+ 更多素材源`；`提示词` 行（右上 `匹配资产` / `放大编辑`）+ 多行输入（占位：`上传并@一个或多个主体、图片，涵盖每个要素及其关系，描述想要生成的视频内容`）；底部条：`1080P 优惠版` + `5秒` + `1个` + 右侧主按钮 `立即生成 ✦ 63`（48h/r12）；最底 `内容由AI生成，请仔细甄别` |

状态机（从 UI 文字推断 🟡）：`未开始 → 剧本 → AI拆分镜 → 分镜(N)`；`AI拆分镜` 旁带 `首次免费` 角标。分镜状态标签 `未定稿`（定稿后应变为其它态）。

交互：
- `添加分镜` → 分镜数 +1（实测 1 → 2）。
- `项目资产` → 打开右侧抽屉式弹窗（见 4.4）。
- `匹配资产` → 依据提示词从项目资产自动匹配（实测仅显示提示 `根据提示词内容自动匹配项目资产`）。
- `3D导演台` → 全屏浮层（见 4.6）。
- 模式 tab 切换后，下方模型/素材/参数区随模式变化（未逐模式取证 ❌）。

- 片段来源：本集 `storyboards`（`shot_no / shot_desc / duration_s / video_task_id`）；播放地址按需取 `GET /tasks/:id/results/0/download-url`（后端 1h 签名 URL）。
- 时间线顺序存 `localStorage["timeline:<projectId>:<episodeId>"]`（更改即保存），**页面上明确标注「服务端时间线/多端同步待后续版本」**，不假装已持久化到后端。
- 播放：`requestAnimationFrame` 推进播放头，按片段时长累计定位当前片段并切换视频源。

### 14.1 后端（`generate-videos` 加可选 `mode`，响应结构不变）

|---|---|---|---|
| `universal_reference`（默认） | 保持原样，scene=`storyboard_reference_video` | `reference_uris` = 全部绑定资产图 | 所有绑定资产须「定稿 + 有图」，否则逐镜 400105 `asset_not_ready` |

### 14.2 前端

### 14.4 已知交互决策（需产品确认，后端已按此实现）

1. 「第一个/前两个合格资产」按**项目资产创建时间**排序（`storyboard_assets` 无排序列，无法复现用户绑定顺序）；若要按绑定顺序当首帧，需给绑定表加列 + 迁移。
2. 幂等按镜头维度：同镜已生成过时切 mode 再投会**复用原任务**（dedupeKey 未含 mode），前端已加提示；若要「切模式即重出片」需要改 745801 幂等语义。
3. `first_frame` / `first_last_frame` 只校验「合格资产数量」，不要求全部绑定资产定稿（`universal_reference` 仍严格全定稿）。
