## 2. 实现要点（逐条对应要求）

### 2.1 首页双入口（新建 / 继续创作）与工具矩阵

- **主卡「短剧工作流」**：点开 `CreateProjectModal`（新建），与旧行为一致。
- **「继续创作」入口**：最近项目存在时，在「最近项目」标题行出现 `继续创作《项目名》`（`data-testid="home-resume"`，1 击直达 `/projects/:id`）。为什么不做成卡内第二个按钮：卡片根节点是 `<button>`，内嵌交互元素是非法 HTML；把整卡改成 `div[role=button]` 又会引入嵌套可交互元素的无障碍问题。
- **副卡「无限画布」**：旧值 `@click="comingSoon(...)"` 只弹「即将上线」，但 `/canvas` 早已落地 → 改为真实跳转。
- **工具矩阵**（旧值 `if (!tool.enabled) return;` = 零反馈）：
  - 视频转绘：`to: /video-redraw/create`、`enabled: true`（产品页已存在；角标「一周会员」保留，语义=会员权益，不是「即将开放」）；
  - 其余 5 张禁用卡：每次点击都 `toast.info`「{名称}正在内测，暂时无法使用」，同时补 `aria-label` 与 `:title`；
  - 三张**没有任何角标**的卡（视频拉片 / 音色修改 / 错字重读）再加一行可见的 `11px` 灰字「内测中，暂未开放」（`.tool-note`，e2e 断言正好 3 个），从此「禁用原因」不依赖 hover。
  - 注意：**没有**用 `aria-disabled`——那样 Playwright 与读屏都会把卡当"不可交互"，而它其实可点（点=解释原因）；改用 `data-unavailable` 标记。

### 2.2 3 步 coach-mark

- 体系照 `ref-coachmark-2026-10-25.png`：紫色实底浮层 + 白字 + `跳过`（白描边胶囊）/ `下一步（1/3）`（白底紫字）+ 目标高亮（1px 淡紫描边 + 9999px 外阴影压暗）。
- 首访：`localStorage of_guide_v1` 不是 `done` → 600ms 后自动出现；跳过 / 完成 / Esc 都写标记。
- 重看：① 壳层头像菜单「新手引导」→ `/home?guide=1`；② 首页 h1 内「重看引导」小胶囊。
- `data-guide-target="workflow" / "tools" / "recent"` 分别锚双入口卡区、工具矩阵、「最近项目」区。
- **第 2/3 步没有竞品同状态证据**（`ref-coachmark` 只有第 1 步），第 2/3 步的文案、锚点与排布是**我方按同体系设计**，不宣称竞品对齐。
- 已知取舍：引导打开时页面被高亮层覆盖，点击会落在浮层上（避免"边看引导边误点"）；Esc / 按钮是唯一退出路径。

### 2.3 顶部居中深色 toast

- `.toasts`：`position: fixed; top: 72px; left: 50%; transform: translateX(-50%)`，列向堆叠、居中对齐。
- `.toast`：`#1b1b20` 底 + `#ffffff1f` 描边 + `13px` 白字，2.6s 自动消失；`pointer-events: auto` 可点掉。
- 错误仍走 inline（弹窗内 `.error`、列表错误态块），**不弹模态**；e2e 断言作品列表错误态出现时页面上没有弹窗遮罩（`works-empty` 为空、错误块可重试）。

4. **第 2/3 步引导无竞品证据**：`ref-coachmark-2026-10-25.png` 只覆盖第 1 步（且锚点是工作台「AI拆分镜」，不是首页）。第 2/3 步属我方设计，不作竞品对齐宣称。
