## 2. 实现要点

### 2.1 D2：项目页时间线 = 只读预览

删除的写路径（不是隐藏按钮，是删代码）：

```text
saveTimeline / persistTimeline / saveTimer / timelineDirty   ← 项目页不再写时间线
addShotClip / moveClip / removeClip / rebuildTimeline        ← 不再增删排序片段
exportTimeline / startTlExportPoll / tlExport*               ← 不再从项目页合成导出
watch(clips, () => saveTimeline(true), { deep: true })       ← 不再把本地改动回写
```

保留的只读能力：片段轨道（`.tl-clip`）、刻度尺、播放头、播放/暂停、缩放、`已定稿` 筛选、点左栏定位播放头（`previewShot`）、点轨道定位（`onTrackSeek`）。

- **点左栏 = 预览定位，不是「加入」**：该镜已在时间线里 → 播放头跳到它的起点；不在 → 提示「该镜还没加入时间线，去剪辑台添加」（`tlPreviewShotMissing`），不假装能加。
- **轨道点击修掉旧错位**：原实现用 `event.offsetX`（台账 §2.4 #18：横向滚动后错位），改成 `clientX - rect.left + scrollLeft`。
- **唯一出路**：`.tl-goto`「去剪辑台 →」→ `/reelflow/edit/{projectId}?ep={episodeId}`；同时写 `localStorage["reelflow:ep:{projectId}"]` 留底。项目页 `loadProject` 也认 `?ep=`，所以「项目页 ↔ 剪辑台」往返不会丢集数。
- 视图名从「时间线导出」改为「时间线预览」（新增 key `viewCards.timelineLabelPreview`，**不改既有 key 的值**），避免菜单文案继续暗示这里能导出。

### 2.2 P1-3：项目页导出记录（真实数据）

- 端点：`GET /projects/:id/exports?page=&page_size=10`（`script.controller.ts:1070` / `listProjectExports`，聚合 `exports` 分镜 zip 与 `timeline_exports` 成片 mp4）。
- 列：**类型**（分镜包 zip / 成片 mp4）、**集数**、**状态**（排队 / 打包 / 已完成 / 失败）、**时间**、**下载**、**有效期**（`expires_at`，过期显示「已过期」，无过期显示「长期有效」）。
- 无下载链接时给可读原因：失败 → 服务端 message（没有才用「失败，无文件」）；未完成 → 「未完成」；已完成但无签名地址 → 「已过期，需重新导出」。不留裸破折号。
- 分页：`total > 10` 才出翻页条；`truncated` 时提示「只展示最近 500 条」。
- 进入导出视图即拉取；提交本集 zip 后立刻刷新（受理即出现在记录里，状态=1），轮询到终态（3/4）再刷新一次（下载签名只有完成才存在）。
- 空态：「还没有导出记录」+ 说明；失败态：页内 banner + 重试按钮（真动作）。

## 4. 未验证项与风险（如实登记）

1. **编辑台还不认 `?ep=`**：`reelflow/edit/[id].vue` 的 `loadProject` 固定取 `episodes[0]`（该文件属 U4 写手，本次未改）。所以「保留集」目前分两段证据：**URL 带集数 ✔ / 本地留底 ✔**，**编辑台按该集载入 ✖（待 U4 消费 `?ep=` 或 `localStorage["reelflow:ep:{projectId}"]`）**。这是本批**唯一未闭环**的验收点，不能在台账里写成「跳转已闭环」。
2. **空间级导出日志端点不存在**：`GET /exports` 每访问一次列表页会打一次 404（静默 `catch`，用户不可见）。这是 D3「有日志才叫已导出」的实现代价；若不接受这个探测，可改成构建期常量，但那样「已导出」分支无法用 e2e 证明。
3. **「已剪辑」tab 目前没有列表内容**（只有口径说明）：唯一可用的项目内信号是 `timeline_duration_s`，而任务书明确禁止用它推断。要给出真正的剪辑列表，需要空间级剪辑日志（与导出日志同一缺口）。
4. **导出记录分页是 page 制**：后端 `listProjectExports` 各链最多取最近 500 条再合并分页，更早的记录看不到（页面已提示 `truncated`）。
5. **下载地址是 1h 签名 URL**：列表缓存不会自动续签；停留过久点「下载」可能失效，需刷新（未做自动续签，避免每行定时打接口）。
6. **e2e 的导出记录是 mock**：证明的是「前端能正确展示 / 分页 / 空态 / 失败态」，不是「真实数据库里有这些行」；真实投影字段以 `script.service.ts:2623` 为准（本次只读复核）。
7. **项目页不再提供「合成导出成片」**（D2 的直接后果）：从项目页导出成片必须先跳剪辑台。属既定决策，但对老用户是行为变化，建议在 U6/U7 引导文案里补一句。
8. **竞品同状态对照**：`08-timeline-inproject.png` 只有项目内时间线的静态形态，竞品「导出面板 / 进度 / 已导出 tab 内容」仍是 0 积分截图缺口（`ref-facts.md` §7.2 #3/#6），因此导出记录表**没有竞品 L1 依据**，只保证「真实、可读、可操作」。
