## 3. 实现要点（与计划条款逐条对应）

1. **`utils/shot-status.ts`**：`apps/web/utils/` 为新建目录；页面显式 `import`（不依赖自动导入），避免同名歧义。
2. **`prefillBudget`**：分桶改为 `isShotCommitted` / `!isShotCommitted`；报价项改为 `buildQuoteItem(shot, 角色立绘)`，与单镜报价同一条代码路径（不再有第二套 `mode: "universal_reference"` 硬编码）。
   `spent` 只对 committed 镜头求和，并在注释中写明「失败任务会退款，失败镜头的旧 task 不计入」。
3. **`matrixClass`**：保留任务失败优先级（`task_status 4/7`），成功走 `task_status===3 || isShotRendered`，运行中走 `isShotInFlight || task_status 1/2`。
4. **`shotStateLabel`**：三态唯一出口（已定稿 / 已投递 / 未定稿），四处共用。
5. **`idempotentTaskId`**：从模板内联三元改为 computed，条件 `isShotCommitted && video_task_id`——失败回归到 `status=2` 的镜头不再误报「重复提交会复用」。
6. **编辑器删除**：页内撤销条（`role="status"`，8s 自动消失）而非 toast 动作；`removedClip` 记录原 index，撤销按原位置插回；`onUnmounted` 清 `undoTimer`。
7. **保存兜底**：`persistTimeline(silent, keepalive)`；`flushPendingSave()` 先清防抖 timer，再在 `dirty` 时用 `{ keepalive: true }` 走同一个 `useApi` 客户端（同源同鉴权，未新造鉴权机制）；`pagehide` / `beforeunload`（`preventDefault` + `returnValue`）/ `visibilitychange(hidden)` / `onUnmounted` 四处触发，均不 `await`。
8. **切片校验**顺序：`start<0` 归零 → `end<=start` → `end>总长`（`editor.endBeyondTimeline`）→ 不足 `MIN_SLICE_S=1`（`editor.sliceTooShort`）。输入框同时加 `:min` / `:max`。
9. **弹窗无障碍**：`aria-modal="true"` + `@click.self="closeModals"` + `ref` 面板 `tabindex="-1"` + `trapFocus`（首尾循环）+ 打开时聚焦第一个可聚焦元素 + 关闭后焦点归还触发按钮；`onKeydown` 顺序为 **Esc → 弹窗守卫 → 输入框过滤 → 全局快捷键**。

## 5. 未验证项与风险（如实登记）

1. **`taskMap` 未加载时 `spent=0`**：`taskMap` 只在批量投递后的轮询里填充；直接进页面点「按报价预填」时「已消耗」会是 0，预算估值偏低。属既有局限（本次不扩大范围），修法在 U3/U4 一并考虑（进页面按 `video_task_id` 批量拉一次任务）。
2. **编辑器「已定稿」闸门的运行时拦截未在 e2e 中逐镜点击验证**：e2e 断言的是 `data-finalized` 标记与左栏列表（默认只列已定稿、全部视图标 0/1），未真的去点未定稿行确认 toast 文案。
3. **`beforeunload` 的原生确认弹窗无法自动化断言**（Playwright 会静默处理 dialog）；已验证的是「刷新后改动仍在」，即 keepalive 写入生效，未验证浏览器确认框出现。
4. **焦点陷阱**只做了 Tab 首尾循环与初始聚焦；未验证 Shift+Tab 从面板外回流（`inside` 分支持有兜底，但无 e2e）。
5. **赔率**：`editor.rendered / notRendered / filterRendered` 三个 key 已不再被引用（全仓 grep 无命中），按计划保留未删除；如需清理放到 U7 统一处理。
6. **视觉**：本批未做 1424×805 同状态竞品对照（U1 不含 L1 目标）；截图仅作我方回归证据。
