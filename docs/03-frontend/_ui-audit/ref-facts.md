## 7. 对「UI 对比」最重要的 5 条竞品设计决策（给 Lead 的摘要）

1. **三列定宽工作台就是"同一产品"的骨架**：160（分镜条）/ 592（素材）/ 640（生成台）+ 8px 缝隙与 8px 外边距，全部面板同底色同圆角 —— 我方若列宽/缝隙/面板材质不一致，第一眼就"不像"。（`measure.json` rect 8/168/176/768/776/1416；`03` 扫描）
2. **一套面板语言贯穿所有页**：底 rgba(194,204,241,.08)（合成 #191A22）、圆角 16/20/24、按钮 40 高圆角 10、品牌激活 rgba(155,70,255,.4)、主按钮 #9B46FF 圆角 12 —— 竞品的"统一感"来自 token 少而稳，不来自细节多。（`measure.json` 全部 controls；`reference-alignment-spec.md:49-60`）
3. **阶段与状态用"胶囊 + 下拉 + 徽标"而不是步骤条**：`未开始 ▾` / `剧本` / `预览` / `未定稿` / `首次免费`，且内页没有 24px 大标题（主标题 16/400）。（`measure.json:10,27`；`reelflow-spec:60,94-99`）
4. **价格与配额贴在动作上、用营销标签表达技术值**：`立即生成 ✦ 63`、`图片 0/30，视频 0/10，音频 0/10，总 0/50`、`1080P 优惠版`（实为 720p 码率）。（DOM `page-episode-create.html:136,140`；`feature-map:363,379,524`）
5. **闸门与显式同步是"可交付感"的来源**：未定稿资产不入分镜/不入时间线；提取后必过 `资产清单校验 → 批量生成资产`；剪辑器与流水线靠 `更新分镜` 显式同步且 tooltip 明说不自动更新。（`09`、`02`、`editor-current.html`、`feature-map:348`）
