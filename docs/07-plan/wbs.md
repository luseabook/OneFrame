**M2（W8 末）**：PRD F2 验收标准全过，逐条列出：
1. 3 集×10 镜、人工干预 ≤5 次、端到端（含排队）≤2h；
2. 一致性注入：同角色各镜任务 references 均含**已定稿**定妆图（服务端保证）；未定稿→400105；
3. 预算：`/credits/quote/batch` 总额=逐镜求和；触顶镜 `code:745703` 且 HTTP 200，未投镜可提高预算续投（显式新预算值）；
4. 参数：UI 只出所选模型 scene 枚举；越界 400101；时长不支持时就近低档回写；
5. LLM 失败/超时(745901)不半写（明确报错可重试、不扣积分）；
6. 失败镜重试不重复扣费（幂等）；
7. 导出可下载（zip=成功镜+manifest，失败可重试）；成功镜 <80% 返回 400106；
8. 导入剧本拆集可用（source_type=3）且不扣积分；
9. AI 双标识抽验通过（视频水印+元数据；图片重编码+标识）。
