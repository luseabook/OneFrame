# 安全设计

> v1.1 · 2026-10-24 · 威胁模型 → 对策；对照 OWASP Top10 与本项目实际面
> v1.1 变更：对账不变式改 database §4 口径（RE-02）；补分享 token 安全（RE-08）

## 1. 资产与威胁模型（STRIDE 摘要）

| 资产 | 主要威胁 | 对策章节 |
|---|---|---|
| 积分账户 | 超支/并发穿透/重复扣费 | §3 计费原子性 + 幂等 |
| 生成任务 | 白嫖刷量/提示词注入攻击系统提示 | §4 频控验证码 + 提示词只当数据 |
| 用户数据(手机号/作品) | 拖库/越权 | §2 + §5 |
| 供应商 Key | 泄露(前端/日志/仓库) | §6 密钥治理 |
| OSS 桶 | 列桶/未授权直读 | §7 私有桶+预签名 |
| 支付 | 伪造回调/重复支付 | §8 回调验签+幂等 |

## 2. 认证与会话

- JWT：HS256+32B 随机密钥（密钥轮换：kid 双密钥并行 7 天）；access 2h，refresh 14d 单次轮换（重放检测：旧 refresh 使用即全家下线并告警）；
- 登出/改密：Redis 黑名单；
- 短信验证码：6 位，5min 有效，错 5 次作废；发送侧频控（api-spec §13）+ 图形/行为验证码前置；
- 越权：所有资源访问强制 `space_id` 属主校验（middleware 统一注入，业务不得自查），测试见 testing §2-5。

## 3. 计费安全（核心不变式）

1. 冻结/结算/解冻全部走 `UPDATE credit_accounts WHERE balance-?, frozen+? …` 带条件的原子语句 + 行锁；
2. 任务与流水同事务（system-design §3.1）；
3. 幂等键 DB 唯一索引兜底（防 Redis 失效双写）；
4. 对账任务每日校验 `balance == Σ delta` 且 `frozen == Σ frozen_delta`（database §4 唯一口径），不平 P1 告警；
5. 前端报价仅展示，服务端以 model_prices 为准重算。

## 4. 滥用防护

| 面 | 措施 |
|---|---|
| 生成刷量 | 用户 10/分 + 新账号首日 20 次/日上限；异常(同提示词高频)→429101 验证码挑战 |
| 提示词注入 | 提示词只作为模型输入数据透传，**永不拼进系统指令/SQL/日志查询**；长度≤2000 白名单字符过滤 |
| 内容安全 | 输入：敏感词库(政治/色情/暴恐) + 供应商审核；输出：供应商审核 + 抽样复审；拦截任务不扣费 |
| 爬虫/扫站 | 全站 WAF(CDN 侧基础规则) + robots 禁工具页 + 蜜罐路径告警 |

## 5. 数据保护（PIPL 对齐，详见 compliance.md）

- 手机号：AES-GCM 字段加密存（密钥 KMS/环境分离），日志掩码；
- 提示词/作品：私有桶，预签名最短必要时长（预览 1h/下载 24h）；
- 删除权：账号注销 → 手机号/头像/资产逻辑删，30 天物理清（订单财务数据依法保留）；
- 传输全 TLS；浏览器端不存 token 于 localStorage（refresh 用 SameSite=Strict HttpOnly Cookie，access 内存态）；
- 分享：token ≥128bit 随机、7 天过期、可撤销；公开页不返回 prompt/uid/空间信息，仅结果元数据与短时预签名；被举报内容可即时下线（撤销该任务全部 token）。

## 6. 密钥治理

- 分级：L1 供应商/支付 Key（仅 worker/api 容器 env）· L2 JWT/加密密钥 · L3 第三方回调 Secret；
- 入库前 gitleaks 扫描（CI）；轮换：L1 季度、JWT 泄露即时（kid 机制）；
- 最小权限：OSS 子账号只授权两桶；供应商账号不开余额自动充值上限。

## 7. 输入与文件安全

- 全端点 Zod 校验（fail-fast 4001xx）；未知字段剔除（防 mass assignment）；
- 上传：扩展名+MIME+魔数三层校验；图片重编码剥离元数据(EXIF/GPS)；视频 ffmpeg probe 校验容器；
- 响应：统一 JSON（无反射 XSS 面）；CSP `default-src 'self'`；Cookie Secure+HttpOnly+SameSite。

## 8. 支付安全

- 微信 V3 回调：平台证书验签 + 解密 + `out_trade_no` 幂等（唯一索引）；
- 订单金额只信服务端 SKU，不信前端；
- 退款走独立审批（后台双人：发起/确认，MVP 单人+延时生效）。

## 9. 依赖与供应链

- CI：`pnpm audit --prod` 高危阻断；镜像固定 digest；renovate 周更 PR；
- 依赖准入：新增运行时依赖需在 PR 说明用途（防 typosquat）。

## 10. 事件响应

P0 安全事件（Key 疑似泄露/拖库迹象）：① 立即吊销轮换受影响密钥 → ② 隔离账户/功能开关 → ③ 取证（日志快照入 OSS 只读桶）→ ④ 24h 内评估是否触发用户告知义务（PIPL/网安法）→ ⑤ 复盘文档。
